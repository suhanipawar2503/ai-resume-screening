# AI Resume Screening & Job Matching System

## Project Overview
A full-stack AI-powered system that analyzes resumes and compares them with job descriptions to help candidates find suitable jobs and recruiters identify suitable candidates.

## Planned Technology Stack
- React + Vite
- Node.js + Express.js
- PostgreSQL
- Python + FastAPI
- Scikit-learn
- spaCy
- pdfplumber

## Architecture
React → Node.js/Express → PostgreSQL
                         ↓
                    Python/FastAPI
                         ↓
                       ML/NLP
