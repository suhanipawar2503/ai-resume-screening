## Important Development Rules
- Do not change the architecture without approval.
- Do not introduce unnecessary technologies.
- Do not use mock data when real APIs exist.
- Do not hardcode secrets.
- Do not expose uploaded resumes publicly.
- Do not let the frontend directly call the ML service.
- Inspect existing code before modifying it.
- Run relevant tests after changes.
- Do not delete working functionality without approval.
- Keep the project suitable for a 3rd-year B.Tech project.
